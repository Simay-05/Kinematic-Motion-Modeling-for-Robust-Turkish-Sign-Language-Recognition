# Kinematic-Motion-Modeling-for-Robust-Turkish-Sign-Language-Recognition
This model uses a balanced subset of 20 sign classes of the Ankara University Turkish Sign Language (AUTSL) dataset, testing 8 combinations for sign language recognition: MediaPipe and MMPose with Random Forest, SVM, Multilayer Perceptron, and BiLSTM. Kinematic features are integrated to improve accuracy of the model.
